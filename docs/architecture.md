# 当前结构与学习边界

## 当前状态

RepoTrail 已确定使用 Python 实现核心逻辑、命令行、后端与 Agent。当前已开始恢复最小入口文件，尚未验证可运行；解析模块、服务与前端尚未实现。

首版范围和验收标准以 [需求分析](requirements.md) 为准。当前先完成最小 Python 命令行入口，再按小功能逐步开发；核心代码由开发者手写。浏览器界面为首版交付范围，进入展示阶段时再细化前端选型。

## 历史实现与验证

旧 Python 版本完成过命令行和目录扫描，清理前共 17 个测试通过。最新源码、测试及相关文档已有本地备份，位置见根目录 README 的“历史备份”。

这属于旧版本的验证记录，恢复后需重新运行测试。当前不提供尚不可用的启动命令。

## 规划中的职责边界

- 命令行：处理参数、展示结果和错误，调用核心功能。
- 文件扫描：收集文件清单，处理过滤规则。
- 语言识别：根据文件特征判断候选语言，不等同于解析成功。
- 语法解析与信息提取：获得语法树，提取符号与源码位置。
- 关系分析：结合导入、作用域等证据解析关系，保留无法确定的情况。
- 存储与导出：保存分析结果和状态，提供明确的数据接口。
- 展示：消费图数据，支持模块概览与分层浏览。
- Agent：调用检索和源码读取工具，组织有证据的解释，并控制执行范围与成本。

这些模块按实际需求逐步实现，当前不预先建立注册器、复杂框架或完整图谱模型。运行追踪将来独立设计；静态调用关系不能当作实际执行顺序。
